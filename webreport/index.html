Refreshing this page

It refreshes by itself after every merge to develop: the merge runs the tests, and this page is rebuilt from that run. Nothing here comes from an unmerged pull request.

To re-verify the current develop on demand, open the CI workflow and use Run workflow. That runs the tests again, so it takes as long as a normal CI run; the page updates when it finishes.
